# Anarchaeology

Images from the early days of Anarchy Online, recovered from the Wayback Machine — fan sites, guild pages and official pages from 1999–2003 that now survive only in the Internet Archive.

Browse it at **https://anarchaeology.github.io/**.

Every picture links back to its saved copy on the Wayback Machine, and each one is dated as early as the evidence allows: a date stored in the file or its address, the original server's date, the day it was first linked on a forum or listed on a gallery page, or the day the Wayback Machine first saved it.

Anarchy Online and its artwork belong to Funcom. Screenshots belong to the players and sites that made them. This is a non-commercial fan archive kept for history — to ask for a picture to be removed or credited, [open an issue](https://github.com/Anarchaeology/anarchaeology.github.io/issues).
